Multimedia Metadata Extraction (Bachelor's Thesis)

  • Swift, EXIF, IPTC, XMP
  • Software Development
  • 2024
  • ES

The problem

Digital files carry metadata that tells their story: camera settings in photos, artist names in audio, compression levels in videos. Yet accessing this information requires juggling different formats and standards. EXIF for images, ID3 for audio, MP4 atoms for video, each with its own rules and quirks. Users need a unified way to view and analyze metadata across file types and understand what information is actually embedded in their multimedia library.

What I built

A Swift application that reads multimedia files in multiple formats and extracts their embedded metadata consistently. The tool identifies and processes EXIF data from images, ID3 and other audio tags from sound files, and MP4 and MOV metadata from videos. The implementation covers the most relevant metadata standards (EXIF, IPTC, XMP) and includes two practical use cases: one for bulk metadata analysis and another for targeted metadata inspection. The application validates extraction accuracy and performance through test cases covering common file formats and edge cases, demonstrating how to parse binary metadata structures and present them in a usable interface.

Outcome

A portfolio piece that demonstrates understanding of multimedia formats and binary file parsing. The project shows how standards like EXIF, IPTC, and XMP work in practice, how to integrate with iOS frameworks for metadata access, and how to design an application that handles real-world messiness: files with missing tags, non-standard encodings, and incomplete metadata. Two working use cases prove the tool solves practical problems. For future work, expanding language support and adding metadata editing capabilities would make the tool production-ready.
